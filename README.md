# Easy 管理面板

命令可视化操作，单文件，零依赖

## 一键安装

```bash
curl -sL https://raw.githubusercontent.com/smallsmalldou/Easylinux/main/e -o /usr/local/bin/e && chmod +x /usr/local/bin/e
```

安装完成后，在服务器输入 `e` 即可打开面板：

```bash
root@debian:~# e
```

## 功能列表

| 选项 | 功能 |
| --- | --- |
| 1 系统状态 | 系统/硬件信息、CPU 占用与 TOP5 进程、内存、磁盘、网络 |
| 2 网络状态 | 出口 IP / 地理位置 / ISP，流媒体（YouTube、Netflix、TikTok 等 7 项）+ AI（ChatGPT、Claude、Gemini 等 6 项）可用性检测 |
| 3 系统日志 | 查看最近 20 条系统日志 |
| 4 清理垃圾 | 子菜单：1 清理磁盘垃圾（apt 孤儿包 / 下载缓存 / 旧日志压缩至 50M / 过期临时文件）；2 清理运行内存（页缓存 / 目录项 / inode 缓存） |
| 5 系统工具 | 软件源管理 / 虚拟内存 / SSH 端口 / 时区 / 语言 / 主机名 / 密码 / 定时重启 / 重启 / Easy 脚本管理 |
| 6 端口状态 | 当前所有监听端口及对应进程 |
| 7 防火墙管理 | ufw 放行/取消端口、开关防火墙、开关 Ping、重置默认策略（防锁死 SSH 保护） |
| 8 文件管理 | 浏览目录、查看/删除/重命名/复制/移动/压缩/解压/改权限 |
| 9 软件管理 | 已装软件列表、搜索、查看详情、卸载（系统关键包双重确认） |
| 10 BBR 加速 | 一键安装/启用/停用/卸载 BBR，自动检测内核支持 |
| 11 SOCKS5 | SOCKS5 / HTTP 代理设置，自动测试连通后生效，临时生效重启失效 |
| 12 Ping 测试 | 国内/国际延迟与丢包检测（纯本地命令）、自定义 Ping、Globalping 全球多国节点检测本机 |
| 13 记事本 | 创建/编辑/删除笔记行，笔记文件跟随脚本目录（notes.txt） |
| 0 退出 | 退出面板 |

## 更新脚本

已安装的面板内即可直接升级：输入 `5`（系统工具）→ `10`（Easy 脚本管理）→ `2`（更新脚本），面板会自动从 GitHub 拉取最新版覆盖当前版本并重启，**笔记文件不会丢失**。

也可以重新执行一次一键安装命令完成覆盖升级。

## 其他

- 需要 root 权限运行：`sudo e`（非 root 会自动提示）
- 卸载：输入 `5 → 10 → 3`，或直接 `rm -f /usr/local/bin/e`（记事本文件会一起删除）
- 源码审查：`cat /usr/local/bin/e`，全部代码可随时查看
