# Easy 管理面板 v1.0

纯本地 bash 服务器管理面板，零下载、零第三方依赖，只用系统自带命令。Debian/Ubuntu 适用。

## 一键安装

```bash
curl -sL https://raw.githubusercontent.com/smallsmalldou/Easylinux/main/e -o /usr/local/bin/e && chmod +x /usr/local/bin/e
```

安装完成后，在服务器输入 `e` 即可打开面板：

```bash
root@debian:~# e
```

## 使用示例

```
  ──────────────────────────────────────
   1) 系统状态
   2) 系统日志
   3) 清理垃圾
   4) 系统工具
   5) 端口状态
   6) 防火墙管理
   7) 文件管理
   8) 软件管理
   9) BBR 加速
  10) 记事本
  11) 退出
  ──────────────────────────────────────
  请输入选项 [1-10]:
```

输入对应数字即可进入功能，例如输入 `1` 查看系统状态：

## 功能列表

| 选项 | 功能 |
| --- | --- |
| 1 系统状态 | CPU 占用 / TOP5 进程 / 内存 / Swap / 磁盘 / 网络信息 |
| 2 系统日志 | 查看最近 20 条系统日志 |
| 3 清理垃圾 | apt 孤儿包、下载缓存、旧日志压缩至 50M、过期临时文件 |
| 4 系统工具 | 软件源管理 / 虚拟内存 / SSH 端口 / 时区 / 语言 / 主机名 / 密码 / 快捷键 / 定时重启 / 重启 / 卸载 |
| 5 端口状态 | 当前所有监听端口及对应进程 |
| 6 防火墙管理 | ufw 放行/取消端口、开关防火墙、重置默认策略（防锁死 SSH 保护） |
| 7 文件管理 | 浏览目录、查看/删除/重命名/复制/移动/压缩/解压/改权限 |
| 8 软件管理 | 已装软件列表、搜索、查看详情、卸载（系统关键包双重确认） |
| 9 BBR 加速 | 一键安装/启用/停用/卸载 BBR，自动检测内核支持 |
| 10 记事本 | 随手记笔记，文件跟随脚本目录（notes.txt） |
| 11 退出 | 退出面板 |

## 其他

- 需要 root 权限运行：`sudo e`（非 root 会自动提示）
- 卸载：`rm -f /usr/local/bin/e`（记事本文件会一起删除）
- 源码审查：`cat /usr/local/bin/e`，全部代码可随时查看
